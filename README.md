# 한자야 놀자! (PlayHanja) 漢

초등학교 1학년부터 시작해 천자문 마스터까지!
부수의 결합 원리를 보여주는 **애니메이션과 어원 이야기**, 그리고 **한자 획순 애니메이션 & 캔버스 직접 따라쓰기**와 **퀴즈**로 완성하는 어린이 한자 학습 웹 애플리케이션입니다.

---

## 🌟 주요 특징

1. **부수 조각 조립 & 변신 애니메이션**
   - 한자를 이루는 부수들이 각자의 방향에서 그림/이모지로 등장
   - 그림들이 하나로 모인 뒤 먹글씨 느낌의 유령 글자를 거쳐 선명한 정자체 한자로 변신!
   - 획수, 부수 의미, 어원 유래 이야기(`story`), 실생활 낱말(`words`) 수록

2. **한자 획순 애니메이션 & 인터랙티브 따라쓰기 (Write Pad)**
   - **표준 획순 애니메이션**: 1획부터 끝까지 순서대로 써지는 붓글씨 획순 재생 (보통/천천히/반복)
   - **미자(米/十) 격자 보조선**과 연한 가이드 폰트 위 붓펜(먹물, 주홍, 청색) 직접 쓰기
   - 가이드 온/오프, 지우기 및 완성 칭찬 스탬프(💮) 피드백

3. **6단계 성장형 학습 단계 (Levels - 총 155자)**
   - 🌱 **1단계: 씨앗 단계** (가장 쉬운 기초 그림 한자 / 상형자·지사자)
   - 🌿 **2단계: 새싹 단계** (자연, 신체, 기본 방향 한자)
   - 🎍 **3단계: 줄기 단계** (기초 결합 회의자, 동물, 가족 한자)
   - 🌳 **4단계: 나무 단계** (학교, 시간, 계절, 색깔 7급 한자)
   - 🍎 **5단계: 열매 단계** (이야기와 부수가 풍부한 심화 생활 한자)
   - 🎓 **6단계: 천자문 마스터** (천지현황, 우주홍황, 일월영측, 진숙열장, 한래서왕, 추수동장, 운등치우, 노결위상 8대 명구 32자 완성!)

4. **11개 테마별 주제 카테고리 (Categories)**
   - 🌤️ **자연 & 요일** (`nature`)
   - 🔢 **숫자 & 단위** (`number`)
   - 🧭 **방향 & 위치** (`direction`)
   - 🧍 **몸과 사람** (`body`)
   - 👨‍👩‍👧 **가족 & 이웃** (`family`)
   - ⏳ **시간 & 계절** (`season`)
   - 🐾 **동물 & 식물** (`animal`)
   - 🎨 **색깔 & 모양** (`color`)
   - 🏫 **학교 & 배움** (`school`)
   - 🏠 **생활 & 나라** (`life`)
   - 📜 **천자문 명구** (`thousand`)

5. **천자문 250구 완당 전용관 (`thousand.html`)**
   - 1구 `天地玄黃`부터 250구 `焉哉乎也`까지 250개 4자 구절 콤팩트 카드 그리드
   - 클릭 시 대형 구절 모달에서 4글자 획순 애니메이션 및 따라쓰기 연습 연동

6. **급수별 한자 공부 1급~9급 (`grade.html`) — 총 1,166자**
   - 한자능력검정 급수 체계를 참고한 **9급(입문) → 1급(최고급) 9단계** 구성
     - 🐣 9급 입문(50자) · 🌱 8급 기초(50자) · 🌿 7급 초급(68자) · 🎍 6급 초급 심화(138자)
     - 🌳 5급 중급(167자) · 🍎 4급 중급 심화(263자) · 🏅 3급 고급(250자) · 🎖️ 2급 고급 심화(90자) · 🏆 1급 최고급(90자)
   - 급수 카드로 단계를 고르고 **한자 / 훈(뜻) / 음(소리)** 검색 지원
   - 글자를 누르면 **표준 획순 애니메이션 + 직접 따라쓰기** 모달이 열리고, 급수별 학습 진도 저장
   - **쓰기 연습장(A4) 탭에서 급수별 한자를 그대로 출력** (20자/40자/80자/급수 전체, 낱장 4자 인쇄)

7. **실제 출력용 A4 한자 쓰기 연습장 & PDF 생성기 (`worksheet.html`)**
   - **A4 1페이지 4글자 표준 워크시트**: 큼직한 미자(米/十) 격자 칸(따라쓰기 2칸 + 스스로 쓰기 4칸)
   - **실생활 낱말 쓰기 칸** 및 **하단 미니 받아쓰기 & 4자 구절 통쓰기 테스트 칸**
   - 단일 구절 인쇄 및 묶음(1~5구, 1~10구, 250구 전체) 원클릭 A4 인쇄 / PDF 저장 지원
   - **두 가지 인쇄 모드**: 📜 천자문 구절 모드 / 🏅 급수별 한자 모드(1급~9급)
     - 급수 모드는 훈·음이 함께 표기되고, 낱말 자료가 없는 한자는 **훈(뜻)·음(소리) 쓰기 칸**이 자동 제공됩니다.

8. **카테고리별 4지 선다형 퀴즈 & 로컬 진도 저장**
   - 카테고리별/전체 한자 퀴즈 생성
   - 학습 완료 체크 및 브라우저(`localStorage`) 저장으로 진도율 확인

## 📁 프로젝트 구조

```
playhanja/
├── css/
│   └── style.css            # 반응형 디자인, 테마, 모달 탭, Write Pad 스타일
├── js/
│   ├── animation.js         # 한자 부수 조립 애니메이션 엔진
│   ├── hanzi-data.js        # 155자 한자 데이터 (부수, 어원, 단어, 레벨, 카테고리)
│   ├── thousand-data.js     # 천자문 250구 1,000자 데이터
│   ├── grade-data.js        # 급수별(1급~9급) 한자 1,166자 데이터 (훈·음)
│   ├── write-pad.js         # 캔버스 인터랙티브 한자 따라쓰기 엔진
│   ├── progress.js          # localStorage 기반 학습 진도 관리 모듈
│   ├── nav.js               # 공통 상단 내비게이션 (모바일 햄버거 메뉴)
│   ├── learn.js             # 한자 배우기 & 모달 인터랙션
│   ├── thousand.js          # 천자문 250구 화면 로직
│   ├── grade.js             # 급수별 한자 학습 화면 로직
│   ├── worksheet.js         # A4 워크시트 인쇄 엔진 (천자문 / 급수 모드)
│   ├── quiz.js              # 4지선다 퀴즈 로직
│   └── main.js              # 메인 홈 인터랙션
├── index.html               # 홈 화면 (서비스 소개 & 데모)
├── learn.html               # 한자 배우기 & 따라쓰기 화면
├── grade.html               # 급수별(1급~9급) 한자 공부 화면
├── thousand.html            # 천자문 250구 전용관
├── worksheet.html           # A4 쓰기 연습장 (인쇄 / PDF)
├── quiz.html                # 퀴즈로 복습 화면
└── README.md
```

## 🚀 실행 방법

별도의 서버 설치 없이 웹 브라우저에서 `index.html`을 열면 즉시 실행됩니다.

```bash
# 로컬 테스트 (선택 사항)
npx serve .
# 또는 브라우저에서 index.html 직접 열기
```
