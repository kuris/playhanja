# 한자야 놀자! 🐉📖

초등학교 1학년부터 시작할 수 있는 **애니메이션 한자 학습 사이트**입니다.
한자를 이루는 부수(그림) 조각들이 하나씩 등장해 자연스럽게 합쳐지고, 그 자리에서 실제 한자가 나타나는 애니메이션을 통해 **부수의 의미 → 한자의 뜻**을 함께 익힐 수 있도록 설계했습니다. 생활 속에서 가장 자주 쓰는 한자(요일, 숫자, 몸, 가족, 학교, 생활)를 먼저 배우도록 순서를 구성했습니다.

## 🎯 프로젝트 목표
- 초등 1학년도 이해할 수 있는 쉬운 설명과 그림 이모지로 한자 학습 진입 장벽을 낮춘다.
- 부수 조각이 모여 한자가 되는 과정을 애니메이션으로 보여줘 "왜 이 한자가 이런 모양인지" 직관적으로 이해하게 한다.
- 생활에서 자주 쓰는 한자(요일, 숫자, 가족, 학교 등)를 우선 학습하도록 커리큘럼을 구성한다.
- 학습 진도를 저장하고 퀴즈로 복습하며 성취감을 느끼게 한다.

## ✅ 현재 구현된 기능

### 1. 홈페이지 (`index.html`)
- 서비스 소개 히어로 섹션 + 자동 반복되는 한자 조립 애니메이션 데모
- "이렇게 배워요" 4단계 이용 방법 안내
- 카테고리(자연&요일, 숫자, 몸과 사람, 가족, 학교, 생활) 미리보기 카드 → 클릭 시 해당 카테고리로 필터링된 학습 페이지 이동
- "한자 애니메이션 미리 보기" 데모 스테이지 (다시 보기 / 다른 한자 보기 버튼)

### 2. 한자 배우기 (`learn.html`)
- 전체 54개 생활 한자를 카드 그리드로 표시
- 카테고리별 필터, 난이도(새싹/나무/열매)별 필터, 검색(뜻/소리로 검색)
- 카드 클릭 시 상세 모달에서:
  - **1단계** 부수 조각(그림 이모지)이 각 방향에서 날아와 한자 실루엣 자리에 모임
  - **2단계(중간 추상화 단계)** 모인 그림들이 점점 흑백으로 흐려지고, 그 위로 붓글씨체의 반투명한 "유령 글자"가 서서히 겹쳐 떠올라 그림이 한자로 변해가는 과정을 보여줌
  - **3단계** 그림이 완전히 사라지고 유령 글자가 선명해지며 최종 정자체 한자로 자연스럽게 안착
  - 재생 중 각 부수의 뜻이 하단 캡션 + "부수 설명 목록"에 순서대로 표시(하이라이트)
  - 한자가 만들어진 유래(이야기), 실생활 예시 낱말 표시
  - "다시 보기" / "천천히 보기(느린 속도)" / "다음 한자" 버튼
  - "다 배웠어요!" 버튼으로 학습 완료 표시(localStorage에 저장)
- 좌측 패널에 전체 학습 진도율(진행 바) 표시

### 3. 퀴즈로 복습 (`quiz.html`)
- 카테고리별로 퀴즈 범위 선택 가능(전체 또는 특정 카테고리)
- 한자를 보고 4개 선택지 중 알맞은 뜻 고르기 객관식 퀴즈(최대 10문제)
- 학습 완료한 한자를 우선 출제
- 정답/오답 즉시 표시, 최종 점수와 이모지 피드백 제공
- "다시 풀기" 버튼으로 재도전 가능

## 🗂️ 데이터 구성
현재 54개 한자를 아래 6개 카테고리, 3단계 난이도로 구성했습니다.

| 카테고리 | 설명 | 예시 한자 |
|---|---|---|
| 자연 & 요일 | 요일 이름에도 쓰이는 자연 한자 | 日 月 火 水 木 金 土 山 川 天 地 雨 雪 |
| 숫자 | 1~10 숫자 한자 | 一 二 三 四 五 六 七 八 九 十 |
| 몸과 사람 | 나와 몸을 나타내는 한자 | 人 大 小 女 子 男 手 口 目 心 足 |
| 가족 | 가족 구성원 한자 | 父 母 兄 弟 家 |
| 학교 | 학교에서 만나는 한자 | 學 校 生 先 敎 室 |
| 생활 | 집, 방향, 전화 등 생활 한자 | 門 車 電 話 上 下 中 左 右 |

각 한자는 `js/hanzi-data.js`에서 다음 정보를 가집니다: 한자, 음(소리), 뜻, 카테고리, 난이도, 획수, 애니메이션에 쓰이는 부수(그림 이모지+설명+등장 방향), 유래 이야기, 실생활 낱말 예시.

## 🔗 주요 경로(URL) 및 파라미터
- `index.html` — 홈페이지
- `learn.html` — 한자 학습 목록 (쿼리 파라미터 `?cat=카테고리id` 로 특정 카테고리 바로 필터링 가능. 예: `learn.html?cat=number`)
- `quiz.html` — 퀴즈 페이지

## 🧩 기술 구조
```
index.html          홈페이지
learn.html           한자 학습 목록 + 상세 모달
quiz.html            복습 퀴즈
css/
  └─ style.css        공통 스타일 + 애니메이션 키프레임
js/
  ├─ hanzi-data.js     한자/카테고리/난이도 데이터 (54자)
  ├─ animation.js       한자 조립+모핑 애니메이션 재생 엔진 (그림→붓글씨 유령글자→정자체, 재사용 가능한 공용 함수)
  ├─ progress.js        학습 진도 저장 유틸 (localStorage 기반)
  ├─ main.js             index.html 전용 스크립트
  ├─ learn.js            learn.html 전용 스크립트 (필터/검색/모달)
  └─ quiz.js             quiz.html 전용 스크립트 (퀴즈 로직)
```

## 💾 데이터 저장 방식
- 한자 학습 데이터(54자, 카테고리, 난이도 등)는 정적 JS 파일(`js/hanzi-data.js`)에 내장되어 있습니다. (별도 테이블/DB 미사용)
- 사용자의 **학습 완료 여부(진도)** 는 브라우저의 `localStorage`에 저장됩니다(`hanzi_learned_ids` 키). 기기/브라우저를 바꾸면 진도가 초기화됩니다.
- 별도의 로그인 시스템은 없습니다.

## 🚧 아직 구현되지 않은 기능 / 제한 사항
- 여러 기기 간 학습 진도 동기화(로그인 없이는 불가능 — 정적 사이트 특성상 서버 인증 미구현)
- 획순(쓰기 순서) 애니메이션은 포함되어 있지 않음(부수 조립 애니메이션 위주)
- 발음 듣기(음성) 기능 없음
- 학부모/교사용 통계 대시보드 없음
- 한자 갯수는 생활 필수 한자 54자로 한정(확장 가능하나 아직 추가되지 않음)
